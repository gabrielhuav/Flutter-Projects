# Flutter projects
Este repositorio contiene una colección de proyectos desarrollados con Flutter.

| Proyecto | Material |
|---|---|
| [HolaMundoFlutter](HolaMundoFlutter/README.es.md) | Primera app Android/iOS: saludo, contador, temas claro/oscuro y tutorial paso a paso en español e inglés. |
| [screens_and_widgets_flutter](screens_and_widgets_flutter/README.md) | Proyecto existente de la colección. |

Para empezar en una Mac sin VS Code ni Flutter, consulta [Inicio en Mac](HolaMundoFlutter/INICIO-MAC.md).

Cada proyecto tiene su propio `pubspec.yaml`: abre su carpeta en el editor y ejecuta los comandos Flutter desde ella.

## Descargar y abrir HolaMundoFlutter

```bash
git clone https://github.com/gabrielhuav/Flutter-Projects.git
```

```bash
cd Flutter-Projects/HolaMundoFlutter
```

La instalación y ejecución se explican en el tutorial del proyecto. El código Android y sus pruebas se verificaron en Windows; la ejecución iOS y sus capturas siguen pendientes de validación en Mac.
